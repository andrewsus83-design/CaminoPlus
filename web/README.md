# camino.plus website

Static marketing site for camino.plus (plain HTML/CSS, no build step on Vercel).

- Pages: `/`, `/features`, `/routes`, `/offline-maps`, `/pricing`, `/faq`, `/about`, `/contact`, `/privacy`, `/terms`, plus `404.html`.
- Styles: `assets/tokens.css` is a copy of `design/tokens.css`; site styles live in `assets/site.css`.
- App screenshots in `assets/screens/` are rendered from the phone mockups in `design/index.html`.
- Background photos in `assets/photos/` are AI-generated (OpenArt), resized to WebP. Check the generator's commercial-use terms and compare landmarks with real photos before launch.
- Pages are generated by `tools/build_web.py` so the header, footer and SEO tags stay in sync. Edit the content there, run `python3 tools/build_web.py web`, and commit the output.

## Deploy on Vercel

Create a separate Vercel project from this repo with **Root Directory = `web`**, Framework preset **Other**, no build command. `vercel.json` turns on clean URLs (`/pricing` serves `pricing.html`). Then add the domain `camino.plus`.

## Before launch

- Replace the "Soon" store badges with real App Store / Google Play links.
- Have Privacy and Terms reviewed by legal counsel (they are marked as drafts).
- Set up the `hello@` and `privacy@camino.plus` mailboxes.
