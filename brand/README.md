# CaminoPlus brand and social content

This folder holds everything needed to make on-brand social media content for CaminoPlus.

| File | What it is |
|---|---|
| [BRAND_GUIDELINE.md](BRAND_GUIDELINE.md) | Who we are, voice, logo, colour, type, photography, layout rules for social. |
| [POSITIONING.md](POSITIONING.md) | What we sell: the stance, the four pillars (the road to Emmaus), the faith lane, and what we may say about the app today. |
| [content-factory/README.md](content-factory/README.md) | How the content plan factory works, step by step. |
| [content-factory/pillars-and-formats.md](content-factory/pillars-and-formats.md) | The 5 content pillars, the 10 repeatable formats, weekly cadence, seasonality. |
| [content-factory/platforms.md](content-factory/platforms.md) | Platform playbook: Pinterest, YouTube Shorts, Threads, X, WhatsApp Channel and more, plus the repurpose map and size cheat sheet. |
| [content-factory/templates.md](content-factory/templates.md) | Fill-in templates: post brief, captions, hooks, Reel/TikTok scripts, carousel, AI image prompts, hashtags. |
| [content-factory/calendar-first-30-days.csv](content-factory/calendar-first-30-days.csv) | A ready starter plan for the first 30 days (pre-launch). Open in Google Sheets or Excel. |
| [content-factory/content-plan-template.csv](content-factory/content-plan-template.csv) | Empty plan sheet with the same columns, for every new month. |
| [content-factory/qa-checklist.md](content-factory/qa-checklist.md) | The check every post passes before it goes out. |

## Ringkasan (Bahasa Indonesia)

- **Brand guideline** = aturan tetap: logo, warna, font, gaya foto, gaya bahasa. Jarang berubah.
- **Content plan factory** = mesin produksi konten yang bisa diulang tiap bulan: pilih pilar dan format, isi brief, pakai template caption dan prompt gambar, cek QA, jadwalkan.
- Bahasa konten: **English**. Platform utama: **Instagram, TikTok, Facebook**. Platform tambahan: **Pinterest, YouTube Shorts, Threads**, lalu **X dan WhatsApp Channel** (lihat `content-factory/platforms.md`).
- Mulai dari `calendar-first-30-days.csv`, lalu tiap bulan salin `content-plan-template.csv` dan ikuti langkah di `content-factory/README.md`.
