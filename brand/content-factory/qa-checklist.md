# QA checklist (every post, before scheduling)

**Message**
- [ ] One clear idea; the hook works in the first line / first 1.5 s / slide 1
- [ ] Gives something useful (fact, tip, feeling or decision)
- [ ] CTA matches the goal in the brief
- [ ] Voice: warm, calm, specific; ≤3 emoji; "pilgrim" not "user"

**Facts and honesty**
- [ ] Distances, stages, dates checked against a reliable source; approximate figures use "~"
- [ ] No feature shown that doesn't exist; "coming soon" stated where true
- [ ] Price is "$11.99 a year" (Pilgrim Plus) or free tier; no invented offers
- [ ] No fake reviews, quotes or statistics
- [ ] AI image of a real place is checked and labelled "AI illustration"
- [ ] UGC: written permission saved, @credit in the first line

**Design**
- [ ] Only brand colours and the 4 brand fonts
- [ ] Text inside the safe zone for that format; readable on a phone at arm's length
- [ ] ≤25 words on any single frame; body text ≥28 px
- [ ] Logo present and not distorted (not needed on credited UGC reposts)
- [ ] Gold text is never on a light background
- [ ] Grid crop (centre square) still reads

**Video**
- [ ] On-screen captions throughout
- [ ] Music is from the platform's commercial library or ours
- [ ] No TikTok watermark on IG/FB versions

**Publishing**
- [ ] Caption first line ≤125 characters
- [ ] Hashtags in range for the platform
- [ ] Alt text written
- [ ] Location tag added (when it's a real place)
- [ ] Link in bio / link sticker is current
- [ ] Sheet status set to `ready`
